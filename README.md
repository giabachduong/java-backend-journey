# Mini Project: Smart Parcel Management System

A console-based backend application for managing parcel deliveries.

## Features

- Add parcel
- Search parcel by ID
- Update parcel status
- Delete parcel
- Save/load parcels from file
- Calculate shipping fee
- Filter pending parcels
- Sort parcels by ID
- Show unique senders

## Technologies Used

- Java
- OOP
- ArrayList
- HashMap
- HashSet
- File Handling
- Streams API
- Lambdas
- Interfaces
- Enums

## Concepts Learned

- Classes and objects
- Encapsulation
- Inheritance
- Polymorphism
- CRUD operations
- Exception handling
- File persistence
- Stream filtering and sorting

## Goal

Prepare for backend internship and Spring Boot development.
